# 六份设计稿映射与核对记录

## 核对方法

六份 PDF 均为单页手机长截图。已对每份 PDF 的唯一页面以 Poppler `pdftoppm` 渲染成 PNG 并逐张目视检查，同时参考文字层核对文案。文字层用于辅助识字，布局与组件判断以渲染图为准。界面是按结构重新实现的，没有将整张稿件截图铺为页面。

## 素材来源与用途

素材从 `bu/docs` 六份 PDF 中通过 `pdfimages` 提取。`src/assets/images` 中命名含 `home/cases/resources/about` 的照片、标志供页面卡片使用；`src/assets/previews/lesson-*` 与 `course-pdf-*` 用作文档预览。提取结果包含透明蒙版对应的小 PNG，不应用蒙版文件。此来源并不构成素材版权或公开使用许可证明；正式发布前确认授权。

## 设计假设清单

1. 首页三个入口分别进入案例库、资源库、关于我们。
2. 资源点击显示本地说明弹窗，因稿件没有详情页/有效链接。
3. 提问箱进入自建页面，最多 500 字，提交仅存当前演示会话并显示本地反馈。
4. 详情预览标签两类都可点；无相应文档的案例显示“待补充”状态。
5. 案例库以四类筛选和四个不同案例演示可检索/可筛选；仅腰旗橄榄球有设计稿所示预览。
6. 联系方式、资源组织关系和未在稿中明确的案例文案均须内容负责人复核。示例案例注明为演示内容。
